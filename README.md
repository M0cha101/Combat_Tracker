## Overview
This project was built to solve the headache of tracking multiple entities during complex combat encounters. It allows Dungeon Masters or players to keep the game moving fast by automating initiative order and status tracking.

### Features
Dynamic Initiative List: Add players and enemies and sort them instantly.

HP Management: Real-time tracking of damage and healing.

Persistent State: [Only include if applicable] Uses LocalStorage to save your encounter even if the page refreshes.

Mobile Friendly: Designed to be used on a tablet or phone behind a DM screen.

### Built With
Frontend: HTML, CSS, JavaScript
